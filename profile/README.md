## Open source

Tools we built for nlook and share with the community.

| Project | What it is |
|---------|------------|
| **[design-from-code](https://github.com/nlook-service/design-from-code)** | A Claude Code plugin & Codex skill that designs UI changes from **real source code** — verify data in code, iterate faithful HTML mockups, lock a design doc, then delegate. Built while designing nlook's own screens. |

```

```
